Una lista inicial de inicio con las herramientas que la mayoría de los visitantes necesitan primero. No es una clasificación por uso: aún no recopilamos los datos para clasificar herramientas, y esta página lo dice.

Una nota honesta sobre esta página

Esta es una lista inicial de inicio, no una medición. Aún no recopilamos datos de uso que puedan clasificar las herramientas por demanda real: nuestra analítica requiere consentimiento y no ha reunido suficientes sesiones para clasificar nada. Las tres herramientas de abajo son los puntos de partida naturales para un visitante nuevo, en el orden en que la mayoría las necesita. Nada aquí es una señal en vivo, y no se muestran números de uso porque no se ha medido ninguno.

Cómo funcionará esta clasificación, cuando pueda

El plan, publicado ahora para que el cambio de inicial a medida sea visible cuando ocurra.

El método previsto

Cuando la analítica con consentimiento haya recopilado suficientes sesiones, la clasificación combinará tres señales: aperturas de herramientas, ejecuciones completadas y cambio semana a semana, ponderadas 60 / 25 / 15 en ese orden. Hasta entonces, esta página sigue siendo una lista inicial de inicio y lo dice.

Qué se mostrará entonces

  • La ventana de medición que cubre la clasificación, en fechas, no «esta semana».
  • El tamaño mínimo de muestra, para que una clasificación construida sobre diez sesiones no se presente como una construida sobre diez mil.
  • Una fecha de última verificación en cada actualización, para que una clasificación desactualizada se vea como desactualizada.

Acerca de esta lista

Por qué la lista es inicial, cuándo se vuelve medida y qué cambiará entonces.

  • ¿Esta clasificación se basa en el uso real?

    No. Es una lista inicial de inicio, no una medición. Aún no tenemos analítica de uso de herramientas con la que clasificar: la analítica requiere consentimiento y no ha recopilado lo suficiente para clasificar nada. Cuando pueda, esta página lo dirá y mostrará la ventana de medición.

  • ¿Por qué estas tres herramientas primero?

    Porque responden a las tres primeras preguntas que hace cada visitante: ¿funcionará en mi PC, cuánto tardará en descargarse y cabrá en mi disco? Son los puntos de partida naturales, no las páginas más abiertas.

  • ¿Cuándo se convertirá esto en una clasificación real?

    Cuando la analítica con consentimiento haya recopilado suficientes sesiones para clasificar las herramientas con honestidad. Eso necesita una ventana de medición, una muestra mínima y una fecha de última verificación: las tres se mostrarán aquí cuando existan.

  • ¿Abrir una herramienta cambia esta lista?

    No. Nada en esta página es una señal en vivo. Las aperturas de herramientas no se cuentan aquí, y el orden no cambia cuando se abre una herramienta.
