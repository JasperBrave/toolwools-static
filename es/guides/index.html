Acerca de las guías

Cómo se escriben, actualizan y eligen las guías.

  • ¿Son estas guías o marketing?

    Guías. Cada una explica un modelo o una decisión con suficiente detalle para comprobarla: la guía de FPS recorre el modelo de seis pasos, la guía de emparejamiento enumera doce emparejamientos reales con veredictos.

  • ¿Con qué frecuencia se actualizan las guías?

    Cuando cambia el modelo subyacente. Una guía que cita una versión de modelo se mantiene fijada a ella hasta que el modelo se vuelve a ejecutar, y el cambio tiene fecha.

  • ¿Qué guías vienen después?

    La gestión del presupuesto de VRAM, asignada frente a usada, y cuándo empieza el tartamudeo, es la siguiente en la cola. Está en borrador; no se promete ninguna fecha hasta que el modelo detrás se valide.

  • ¿Puedo sugerir un tema de guía?

    Sí, usa el formulario de contacto y elige Comentarios sobre herramientas. Los temas que se corresponden con un modelo que podemos validar entran en la lista.
