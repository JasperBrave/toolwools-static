Wie deine GTA-6-Bereitschafts-Note zusammengesetzt wird

Fünf Eingaben, vier Sub-Scores, eine Buchstaben-Note.

  1. 01

    Gib den ganzen Build ein, nicht nur die GPU

    GPU, CPU, RAM, freier Speicher, Laufwerks-Typ und Download-Geschwindigkeit. Der Leistungs-Sub-Score nutzt die gleiche Engine wie der FPS-Rechner, RTX 4090 = 100, 14900K / 7800X3D = 100, und volle Speicher-Punkte brauchen 212 GB frei auf einer SSD bei 111 Mbps oder besser.

  2. 02

    Vergleiche deine Note mit dem S-bis-F-Band

    Das gewichtete Gesamt entspricht einer Buchstaben-Note. Urteils-Text ist deterministisch pro Band, sodass das gleiche Rig immer die gleiche Note landet und zwei Rigs mit einem Punkt Abstand nie widersprüchlichen Rat bekommen.

  3. 03

    Behebe das schwächste Glied zuerst, nicht das lauteste

    Der niedrigste Sub-Score wird explizit genannt und mit dem Rechner verlinkt, der ihn diagnostiziert, Bottleneck, VRAM, Speicher-Planer oder Download-Zeit. Ein starker Sub-Score zu upgraden bewegt die Note kaum.

Sub-Score-Gewichtungen hinter der Note

Vier Sub-Scores werden auf einer 0–100-Skala berechnet und gewichtet. Leistung nutzt die FPS-Engine bei einem Referenz-1080p-Hoch-nativ-Ziel (60 FPS = 100). VRAM vergleicht Karten-VRAM mit dem geschätzten 1080p-Hoch-Bedarf mit einem 15-%-Headroom-Bonus. Speicher ist (freie GB / 212) × Laufwerks-Typ-Multiplikator (NVMe 1,0, SATA 0,9, HDD 0,35). Netzwerk ist (Mbps / 111), gecappt bei 100.

readiness = perf × 0.55 + vram × 0.20 + storage × 0.15 + network × 0.10

perf     = clamp(fps_1080p_high_native / 60 × 100, 0, 100)
vram     = clamp((cardVram / vramNeeded − 0.5) / (1.15 − 0.5) × 100)
storage  = clamp(freeGB / 212 × 100) × driveMult
network  = clamp(mbps / 111 × 100)

grade  = S 92+ · A 82 · B 70 · C 55 · D 40 · F <40
  • Leistungs-Gewicht (0,55) spiegelt, dass Bildrate jede andere Launch-Beschwerde in den RDR2- und Cyberpunk-2077-Post-Launch-Subreddit-Analysen überragt.
  • VRAM (0,20) ist von Leistung getrennt, weil VRAM-Knappheit Stottern verursacht, das rohe Ø-FPS-Zahlen verbergen, es verdient sein eigenes Signal.
  • Speicher (0,15) wendet einen HDD-Multiplikator von 0,35 an: mechanische Laufwerke verursachen Open-World-Streaming-Stalls unabhängig von freiem Platz.
  • Netzwerk (0,10) ist das kleinste Gewicht, weil es nur das Launch-Wochen-Erlebnis beeinflusst, aber ein gestallter Pre-Load ruiniert die Launch-Nacht für einen Voll-Punkte-Build.
  • Noten-Schwellen (S 92 / A 82 / B 70 / C 55 / D 40) wurden so abgestimmt, dass ein Mainstream-2024-Mittelklasse-Build (RTX 3060 + Ryzen 5) mit 16 GB RAM, einer SSD und 150 Mbps 97 (Note S) unter diesem Modell erreicht, B (70+) ist die angestrebte Basis für einen geschmeidigen Launch.

Readiness-Score-Fragen

Was die Note bedeutet und was zuerst zu beheben ist.

  • Gib deine GPU, CPU, RAM, freien Speicher, Laufwerks-Typ und Internet-Geschwindigkeit ein. Dieses Tool setzt die Ausgaben der FPS-, VRAM-, Speicher- und Download-Zeit-Rechner zu einem einzigen gewichteten 0–100-Score mit einer Buchstaben-Note zusammen. Alles B (70+) ist ein geschmeidiger Launch, unter D (40) bedeutet, mindestens eine Komponente blockiert ein gutes Erlebnis.

  • 70 (B-Note) ist die praktische Untergrenze für einen bequemen Launch, 60 FPS bei 1080p Hoch, VRAM schafft es, 212 GB frei auf einer SSD und genug Bandbreite, um einen 212-GB-Pre-Load in etwa 4,2 Stunden fertigzustellen. 82 (A) bedeutet, du kannst Einstellungen am ersten Tag hochschieben, 92+ (S) ist Flaggschiff-Territorium mit 4K + RT im Blick.

  • Nein, 16 GB schafft die Basis dieses Tools. Verdoppeln auf 32 GB zahlt sich nur aus, wenn du multitaskst (Discord, Browser, Streaming) oder wenn du modden willst. Unter 16 GB wendet die FPS-Engine eine 18-%-Durchschnitts- und 40-%-1-%-Low-Strafe an, sodass 8-GB-Builds den Leistungs-Sub-Score versenken, selbst mit starker GPU.

  • Ja, wenn 212+ GB davon frei sind. GTAs Installation ist bis zu 212 GB groß vor dem Day-One-Patch. Auf einer 500-GB-SSD mit Windows und ein paar anderen Spielen installiert, erwarte, dass es knapp wird, plane mindestens 212 GB Headroom in der Launch-Woche ein.

  • Dieses Tool vergibt volle Netzwerk-Punkte bei 111 Mbps, das stellt einen 212-GB-Download in etwa 4,2 Stunden fertig. 50 Mbps sind in etwa 9,4 Stunden fertig, 25 Mbps in etwa 18,8 Stunden. Bei ADSL starte Pre-Loading in dem Moment, in dem Rockstar die Warteschlange öffnet.

  • Mittelklasse-Gaming-Laptops (RTX 3060 Mobile / RTX 4050+) mit 16 GB RAM und einer NVMe-SSD landen typischerweise im B–C-Territorium bei 1080p Mittel/Hoch. Ultra-dünne Laptops mit iGPU oder MX-Klasse-GPUs scheitern am Leistungs-Sub-Score glatt, kein Readiness-Score rettet eine unter-Spec-dGPU.

  • Das Spiel installiert und startet trotzdem auf Hardware unter Rockstars Untergrenze, aber Leistung ist unvorhersehbar, erwarte unter-30-FPS-Durchschnitte, Low-1-%-Stottern und VRAM-Textur-Pop-in. Die F-Note dieses Tools bedeutet, du solltest Vorbestellung als Platzhalter behandeln und entweder das schwächste Glied upgraden oder auf Optimierungs-Patches warten.

  • Dieses Tool nutzt Raytracing aus als Referenz. RT-Aktivieren beim Launch halbiert grob den FPS-Sub-Score auf gleicher Hardware, prüfe den FPS-Rechner direkt mit deinem Ziel-Preset, um das RT-an-Delta zu sehen. VRAM-Headroom schrumpft auch um 1–2 GB mit RT an.

Scoring-Begriffe

Readiness-Score
Eine einzige 0–100-Zahl, die Leistung, VRAM-Headroom, Speicher und Internet zu einer gewichteten Bewertung kombiniert.
Schwächstes Glied
Der niedrigste deiner vier Sub-Scores. Ihn zu beheben ist immer das Upgrade mit dem höchsten ROI, weil er der ist, der deine Note runterzieht.
Noten-Kurve
S 92+, A 82, B 70, C 55, D 40, F <40. B oder besser bedeutet einen geschmeidigen Launch, D oder schlechter bedeutet, mindestens eine Komponente blockiert ein gutes Erlebnis.
Pre-Load
Das Fenster vor dem Launch am 19. November 2026, als Rockstar den Download öffnete, sodass das Spiel um 00:00 Uhr spielbereit war. Dein Netzwerk-Sub-Score entscheidet, ob du rechtzeitig fertig wirst.
