How the minimum and recommended specs were derived

Every component is normalised to a 0–100 tier score. A weighted average produces a single number: below 35 is under-spec, 35–47 clears minimum, 48–81 hits recommended, 82+ is ultra territory. GPU dominates because rasterisation and ray tracing scale almost linearly with it in Rockstar's engine.

score = GPU × 0.55 + CPU × 0.30 + RAM_normalised × 0.10 + storage_type × 0.05
verdict = below   if score < 35
         min     if score < 48
         rec     if score < 82
         ultra   otherwise
  • GPU weight (0.55) reflects that rasterisation performance is the single strongest predictor of GTA-engine framerate, the same finding Digital Foundry reported across the RDR2 PC benchmarks.
  • CPU weight (0.30) is separated because Rockstar's engine is CPU-bound at high refresh rates: even a flagship GPU is starved by a Ryzen 5 1600.
  • RAM (0.10) is capped at 32 GB, beyond that, extra memory helps modding and streaming but not the base game.
  • Storage (0.05) uses a simple binary because the practical gap is HDD vs SSD; SATA vs NVMe difference is < 3 fps in open-world streaming tests.
  • Tier thresholds (35 / 48 / 82) were tuned so an RTX 3060 + Ryzen 5 5600X + 16 GB + SSD, the modal 2024 Steam Survey build, lands in Recommended (score 51), the intended baseline for a smooth launch.

Spec-sheet terms explained

Tier score
A 0–100 number assigned to each component based on its real-world performance relative to today's flagship (RTX 4090 / 14900K = 100).
Bottleneck
When one component (usually CPU) limits the frame rate the rest of the system could otherwise deliver.
VRAM
Video memory on your GPU. 8 GB is the modern floor; 12 GB+ is safer for 1440p and high-res textures.
Ray tracing
Physically accurate lighting simulation. Beautiful but expensive, halves frame rate on comparable rasterised settings.
