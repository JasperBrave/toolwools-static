Contact

Parlez aux personnes derrière les outils

Signalez un bug, corrigez un nombre, suggérez un outil ou proposez un partenariat. Chaque message va à l'équipe éditoriale, pas de robots, pas de numéros de ticket.

Où va votre message

Quatre files, une équipe. Choisissez l'itinéraire qui correspond à votre message et il arrive d'abord à la bonne personne.

Rapport de bug

Quelque chose sur le site se comporte mal, un calcul cassé, un lien mort, un défaut de mise en page. Joignez une capture d'écran ou les entrées exactes si vous le pouvez.

Correction de données

Un niveau, un prix, une spécification ou un score qui ne correspond pas à votre configuration. Donnez-nous l'outil, la valeur que nous avons donnée, la valeur que vous avez mesurée et comment vous l'avez mesurée.

Retour sur l'outil

Dites-nous ce qu'un outil fait mal, ce qu'il devrait faire ensuite ou ce qu'il faut construire. Le retour va dans la même file que celle dont la feuille de route est tirée.

Partenariat

Propositions commerciales, de presse ou de distribution. Nous répondons au courrier de partenariat comme au reste : par écrit, avec un nom joint.

Envoyer un message

Votre e-mail est utilisé uniquement pour répondre à ce message. Il n'est ajouté à aucune liste. Si le formulaire ne peut pas atteindre la boîte de réception, il le dira clairement et proposera une adresse e-mail à la place.

Ce qui se passe ensuite

  1. Réception. Vous voyez la confirmation sur cette page dès que le message arrive dans notre boîte de réception.
  2. Tri. Les bugs et les corrections de données passent d'abord, généralement sous deux jours ouvrables, les autres courriers suivent dans l'ordre.
  3. Reproduction. Pour une correction de données, nous relançons le cas sur la configuration de référence avant que quoi que ce soit change.
  4. Réponse. Nous répondons par écrit, à l'adresse que vous avez donnée. Si un correctif est livré, il est daté dans le journal des modifications de l'outil.

Vous préférez l'e-mail ? Écrivez à hello@toolwools.com, ou corrections@toolwools.com pour les nombres erronés.

Avant d'envoyer

Délais de réponse, quoi inclure et ce qui arrive à votre message.

  • À quelle vitesse aurai-je une réponse ?

    Les bugs et les corrections de données sont triés d'abord, généralement sous deux jours ouvrables. Les retours généraux et le courrier de partenariat sont répondus par écrit, dans l'ordre d'arrivée.

  • Que dois-je inclure dans un rapport de bug ?

    L'outil et la page, les entrées exactes que vous avez utilisées, ce qui s'est passé et ce que vous attendiez. Une capture d'écran du résultat aide, et un nom et une version de navigateur aident encore plus.

  • Ai-je besoin d'un compte pour vous contacter ?

    Non. Il n'y a pas de comptes sur ce site. Le formulaire demande un e-mail pour que nous puissions vous répondre, cette adresse est utilisée uniquement pour répondre à ce message.

  • Qu'arrive-t-il à mon message ?

    Il est stocké dans notre boîte de réception de contact et lu par l'équipe éditoriale. Il n'est pas vendu, partagé ou ajouté à une liste de diffusion. Consultez la politique de confidentialité pour le détail complet de conservation.

  • Puis-je signaler un nombre erroné ici ?

    Oui, choisissez Correction de données, et incluez l'outil, la valeur que nous avons donnée, la valeur que vous avez mesurée et comment vous l'avez mesurée. Les corrections sont reproduites sur la configuration de référence avant qu'un correctif soit livré.
