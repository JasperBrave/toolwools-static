How this ranking will work, once it can

The plan, published now so the switch from seeded to measured is visible when it happens.

The planned method

When consent-gated analytics has collected enough sessions, the ranking will combine three signals: tool opens, completed runs, and week-over-week change — weighted 60 / 25 / 15 in that order. Until then, this page stays a seeded starter list and says so.

What will be shown then

  • The measurement window the ranking covers, in dates, not "this week".
  • The minimum sample size, so a ranking built on ten sessions is not presented like one built on ten thousand.
  • A last-verified date on every refresh, so a stale ranking is visible as stale.

About this list

Why the list is seeded, when it becomes measured, and what will change then.

  • Is this ranking based on real usage?

    No. It is a seeded starter list, not a measurement. We have no analytics on tool usage to rank from yet — analytics is consent-gated and has not collected enough to rank anything. When it can, this page will say so and show the measurement window.

  • Why these three tools first?

    Because they answer the first three questions every visitor asks: will it run on my PC, how long will it take to download, and will it fit on my drive. They are the natural starting points, not the most-opened pages.

  • When will this become a real ranking?

    When consent-gated analytics has collected enough sessions to rank tools honestly. That needs a measurement window, a minimum sample, and a last-verified date — all three will be shown here when they exist.

  • Does opening a tool change this list?

    No. Nothing on this page is a live signal. Tool opens are not counted here, and the order does not change when a tool is opened.
