Como esta classificação funcionará, quando puder

O plano, publicado agora para que a mudança de inicial para medida seja visível quando acontecer.

O método previsto

Quando a análise com consentimento tiver coletado sessões suficientes, a classificação combinará três sinais: aberturas de ferramentas, execuções concluídas e mudança semana a semana, ponderados 60 / 25 / 15 nessa ordem. Até lá, esta página continua sendo uma lista inicial de início e diz isso.

O que será mostrado então

  • A janela de medição que a classificação cobre, em datas, não «esta semana».
  • O tamanho mínimo da amostra, para que uma classificação construída sobre dez sessões não seja apresentada como uma construída sobre dez mil.
  • Uma data de última verificação a cada atualização, para que uma classificação desatualizada seja visível como desatualizada.

Sobre esta lista

Por que a lista é inicial, quando ela se torna medida e o que mudará então.

  • Esta classificação é baseada no uso real?

    Não. É uma lista inicial de início, não uma medição. Ainda não temos análise de uso de ferramentas para classificar: a análise requer consentimento e não coletou o suficiente para classificar nada. Quando puder, esta página dirá isso e mostrará a janela de medição.

  • Por que estas três ferramentas primeiro?

    Porque respondem às três primeiras perguntas que cada visitante faz: vai rodar no meu PC, quanto tempo vai levar para baixar e vai caber no meu disco? São os pontos de partida naturais, não as páginas mais abertas.

  • Quando isso se tornará uma classificação real?

    Quando a análise com consentimento tiver coletado sessões suficientes para classificar as ferramentas com honestidade. Isso precisa de uma janela de medição, uma amostra mínima e uma data de última verificação: as três serão mostradas aqui quando existirem.

  • Abrir uma ferramenta muda esta lista?

    Não. Nada nesta página é um sinal ao vivo. Aberturas de ferramentas não são contadas aqui, e a ordem não muda quando uma ferramenta é aberta.
