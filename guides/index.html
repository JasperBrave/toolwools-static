About the guides

How guides are written, updated, and chosen.

  • Are these guides or marketing?

    Guides. Each one explains a model or a decision in enough detail to check it — the FPS guide walks the six-step model, the pairing guide lists twelve real pairings with verdicts.

  • How often are guides updated?

    When the underlying model changes. A guide that cites a model version stays pinned to it until the model re-runs, and the change is dated.

  • What guides are coming next?

    VRAM budgeting — allocated vs used, and when stutter starts — is next in the queue. It is in draft; no date is promised until the model behind it is validated.

  • Can I suggest a guide topic?

    Yes — use the contact form and choose Tool feedback. Topics that map to a model we can validate go on the list.
